## テーブルの概要

| テーブル名 (Physical) | 論理名 (Logical) | 概要説明 |
| --- | --- | --- |
| users | 会員テーブル | 会員の基本情報、認証情報、会員ランクなどを管理する。 |
| categories | カテゴリテーブル | 商品の階層構造カテゴリを管理する。 |
| products | 商品テーブル | 商品の基本情報、価格、在庫数などを管理する。 |
| product_variants | 商品バリエーション | 色やサイズなど、商品に紐づくバリエーション情報を管理する。 |
| orders | 注文ヘッダー | 注文の全体情報、配送先、ステータス、合計金額を管理する。 |
| order_items | 注文明細 | 注文に含まれる具体的な商品とその数量、単価を管理する。 |
| product_reviews | レビューテーブル | 商品に対するユーザーの評価とコメントを管理する。 |
| wishlists | お気に入りテーブル | ユーザーが後で購入するために保存した商品リストを管理する。 |
| coupons | クーポンテーブル | 割引コード、割引率、利用期限などを管理する。 |
| inventory_logs | 在庫ログテーブル | 商品の在庫増減（入荷・販売・返品等）の履歴を管理する。 |
